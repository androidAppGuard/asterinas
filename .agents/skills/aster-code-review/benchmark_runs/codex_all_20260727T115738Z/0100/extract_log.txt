# aster-code-review

Review code against Asterinas's coding guidelines
— the persona-keyed pages under `book/src/to-contribute/coding-guidelines/`
— and write one Markdown review file.
The review is **recall-first**: miss as few real defects as possible.
It makes both objective calls (undeniable bugs) and subjective calls (guideline violations, each grounded in a cited rule).

There are two review modes, both **anchored at the current checkout (HEAD)**:

- **`diff <base>`** — a Git change:
  the **commit series** the branch adds over its merge-base with `<base>`
  — each commit's message *and* its diff,
  so the review covers per-commit intent and commit hygiene, not just the net change.
  (Commit first; uncommitted edits are not reviewed in diff mode.)
- **`files <path[:lines] ...>`**
  — target code: the working-tree contents of the named files,
  optionally narrowed to line ranges.

To review at a specific commit, check it out first (it becomes HEAD).

This skill is agent-agnostic (Claude Code and Codex).
Only step 3's spawn primitive differs between agents;
everything else is identical.

## Interface

However the skill is triggered,
it receives ONE raw argument string that begins with a mode word:

```
diff   <base>              <output> [--overwrite] [--per-persona-context=auto|yes|no]
files  <path[:lines] ...>  <output> [--overwrite] [--per-persona-context=auto|yes|no]
```

- `<base>` (diff) — **required**,
  any ref or SHA;
  reviews the commit series `merge-base(<base>, HEAD)..HEAD` (each commit's message + diff).
- `<path[:lines] ...>` (files) — **required**, one or more targets in the working tree.
  A target is a path, optionally `path:N-M` or `path:N-M,K-L` (1-based, inclusive);
  repeat a path to add ranges.
  Wrap a path in double quotes to allow spaces or colons (`"a: b.rs":10-20`).
- `<output>` — **required, last positional** (`cp src... dest` style);
  refuse to overwrite unless `--overwrite`.
- `--overwrite` — replace the output file if it already exists.
- `--per-persona-context` — `yes`: fan out one isolated agent per persona (best recall).
  `no`: one combined agent reviews all personas (cheaper, lower recall).
  `auto` (default) currently resolves to `yes`;
  it will become a benchmark-driven heuristic.
  Controls step 3 only.

**Do not pre-split the argument string yourself.**
Pass it verbatim, as a single quoted argument,
to `resolve_target.sh` (step 1)
— the script self-tokenizes (whitespace-split except inside double quotes),
which keeps the parse deterministic and identical across agents.

## Pipeline

Run these steps in order.
Steps 1 and 5 are deterministic scripts;
steps 6–8 use the model.

The helper scripts live in the skill's own `scripts/` directory,
at `.agents/skills/aster-code-review/scripts/` inside the repository under review.
**Invoke every script by its absolute path**
— the working directory is the code under review (the repo root), *not* the skill directory,
so a bare `scripts/…` is not found (notably on Codex, which runs commands from the repo root; do not `cd` into the skill dir either — `resolve_target.sh` needs the repo as its cwd).
Shells do not persist between commands,
so **set `SKILL` at the start of each command that uses it** (or inline the `$(git rev-parse …)`):

```sh
SKILL="$(git rev-parse --show-toplevel)/.agents/skills/aster-code-review"; "$SKILL/scripts/resolve_target.sh" '<raw args>'
```

The steps below write `$SKILL/scripts/…` as shorthand for that absolute path.

1. **Resolve the target.**
   `"$SKILL/scripts/resolve_target.sh" '<raw args>'` prints the canonical review input
   — the commit series (each commit's message + diff) in `diff` mode,
   annotated file excerpts in `files` mode;
   save it to a temp file.
   Run it again with `--meta` first (`"$SKILL/scripts/resolve_target.sh" --meta '<raw args>'`) to get
   `mode=`, `base=`/`files=`, `head=`, `branch=`, `output=`, `overwrite=`, `per_persona_context=`;
   add `date=` (today) and an optional `title=` to make the meta file.
   Pass the raw argument string as a single quoted argument
   so the script's tokenizer sees it intact.
2. **Activate personas.**
   Pick which of the five personas run,
   from the reviewed paths — changed paths in `diff` mode,
   named paths in `files` mode (see *Activation*).
3. **Fan out.**
   Spawn the persona passes (see *Spawning*).
   With `per_persona_context` = `yes` or `auto` (the default),
   run **one isolated PASS per activated persona** — best recall.
   With `no`, run **one combined PASS** over all activated personas in a single context
   — cheaper, lower recall.
   Build each pass's prompt deterministically with `"$SKILL/scripts/build_pass_prompt.sh" <input-file> <persona>...`
   — one persona for fan-out, all activated personas for combined
   — and spawn the sub-agent with **that exact text**.
   Each pass returns a JSON array of comments;
   file each under its persona's `<fragdir>/<persona>.json` (the comment's `persona` field says which),
   so step 5 is unchanged.
4. **Collect** the per-persona JSON fragments.
5. **Assemble.**
   `"$SKILL/scripts/assemble_review.sh" [--overwrite] <meta> <fragdir> <output>` performs the deterministic merge (group by persona in fixed order, sort by file→line, drop exact duplicates *within a persona*, write frontmatter, leave a `<!-- SUMMARY -->` placeholder).
   Pass `--overwrite` only if the user gave it;
   otherwise the script refuses to clobber an existing `<output>`.
6. **Verify** (see *Verification*).
7. **Consolidate** (see *Consolidation*).
8. **Summary.**
   Replace `<!-- SUMMARY -->` with a constructive summary over the final comments:
   what the code does well, the top issues ranked by severity,
   any structural recommendations.

## Activation

A persona runs unless the reviewed paths *provably* contain nothing in its remit (reviewed paths = changed paths in `diff` mode, named paths in `files` mode):

- **maintainability, development, security** — any reviewed code.
- **hardware** — a reviewed path is assembly (`*.S`, `*.asm`),
  an architecture directory (`.../arch/...`), or contains `asm!` / `global_asm!`.
- **documentation** — a reviewed path is `book/`, any `*.md`,
  syscall-coverage files (`*.scml`), or a user-facing API surface (a syscall or kernel parameter).

Activation is path-based and deterministic;
do not use a model to triage (a wrongly-skipped persona is a silent recall hole).

## Pass contract

The shared reviewer contract
— the review methodology and the JSON comment schema every pass must follow
— lives in [`scripts/pass_contract.md`](scripts/pass_contract.md),
inlined as the **stable head** of every pass prompt by `build_pass_prompt.sh` (step 3).
Do not paraphrase it into the prompt yourself:
retyping it breaks the byte-identical prefix the prompt cache relies on (see [`execution_model.md`](spec/execution_model.md)).
A pass reads only the persona block(s) it is given (selective exposure),
reviews the **REVIEW INPUT** at the foot of the prompt,
and returns a JSON array of comments per that schema.

## Spawning a pass

Build every pass prompt with `"$SKILL/scripts/build_pass_prompt.sh" <input-file> <persona>...`
and spawn the sub-agent with its **exact** output
— only a script keeps the prompt's stable head (contract + guideline) byte-identical across passes and reviews,
which is what lets the prompt cache reuse it (see [`execution_model.md`](spec/execution_model.md)).

**Default (`per_persona_context` = `yes`/`auto`)**
— one pass per activated persona,
each in a CLEAN context with only its own persona block (selective exposure):

- **Claude Code** — spawn a Task sub-agent per persona.
- **Codex** — run `codex exec "<build_pass_prompt.sh output>"` per persona
  (pass the built PROMPT TEXT as the argument).

**Never spawn a pass by re-running `aster_code_review.sh` / `run_agent.sh`,
nor by re-issuing the skill's own arguments** (e.g. `codex exec … diff <base> <out>`).
A pass is a *reviewer* invocation whose input is the `build_pass_prompt.sh` text
— not another run of this skill.
Re-entering the launcher spawns another orchestrator that spawns another … , an infinite fork bomb;
the launcher now refuses it (`ACR_AGENT_RUNNING`).

Passes are independent;
order does not matter.
Collect each pass's JSON.

**Combined (`per_persona_context` = `no`)**
— build ONE prompt with all activated personas (`"$SKILL/scripts/build_pass_prompt.sh" <input> <p1> <p2> ...`)
and run a single pass;
it reviews through every lens at once and tags each comment with its `persona`.
The input and spawn overhead are paid once,
so it is cheaper
— but a larger shared context dilutes focus,
so it finds fewer defects.
The default stays fan-out:
recall comes first,
and `no` is an explicit, opt-in concession.

## Verification (step 6)

For each comment, isolate the key premise it rests on
— especially an external-system fact (Linux/POSIX behaviour, the System V ABI, Rust semantics).
Try to **refute** it:
re-read the cited code and consult an authoritative source.
Assign a verdict:

- **confirmed** — keep the comment unchanged.
- **uncertain** — keep it, but prefix `problem` with `(unverified) `.
- **refuted** — remove the comment,
  and append it to a `## Retracted by verification` list at the foot of the file with a one-line reason.

Remove **only** on confident refutation;
an unsure check is `uncertain`, not `refuted`.
This is the only step that may remove a comment, and only false positives.

## Consolidation (step 7)

Find clusters of comments that share one root cause or one fix
(e.g. several manual lock/unlock pairs that all want RAII).
For each cluster, write a single unified fix
and repoint each member's `**Fix.**` at it ("Shared with the other `raii` comments: …").
**Never remove a comment**
— every symptom stays at its own location.

## Output format

The assembled file is:
frontmatter (`date`, `mode`, `base` or `files`, `head`, `branch`, optional `title`),
a `# Summary`,
then a `## <section>` per persona in the order **Maintainability, Correctness, Security, Hardware, Documentation** (Correctness is the Development persona's section).
Each comment is a `### \`file\` line N` subsection:
a quoted ` ```diff ` snippet,
then a prose line `` `<grounding>` (<severity>): <problem> ``,
then a `**Fix.**` paragraph.
Do not restructure what the script emits;
only fill the summary and apply the verify/consolidate edits.

   337	    S::Value: ParseFlag,
   338	{
   339	    let last = match occurrences.last() {
   340	        Some((_, val)) => *val,
   341	        None => return,
   342	    };
   343	    match S::Value::parse_flag(last) {
   344	        Ok(v) => storage.store_param(v),
   345	        Err(_) => log::warn!("invalid value for flag '{}'", name),
   346	    }
   347	}

   358	// Splits the command line string by spaces but preserve
   359	// ones that are protected by double quotes(`"`).
   360	fn split_arg(input: &str) -> impl Iterator<Item = &str> {
   361	    let mut inside_quotes = false;
   362	
   363	    input.split(move |c: char| {
   364	        if c == '"' {
   365	            inside_quotes = !inside_quotes;
   366	        }
   367	
   368	        !inside_quotes && c.is_whitespace()
   369	    })
   370	}

   372	fn dispatch_params(cmdline: &str) -> InitprocArgs {
   373	    let mut result: InitprocArgs = InitprocArgs {
   374	        argv: Vec::new(),
   375	        envp: Vec::new(),
   376	    };
   377	
   378	    let mut kcmdline_end = false;
   379	
   380	    // Step 1: Tokenize and group by normalized parameter name.
   381	    let mut grouped: BTreeMap<String, Vec<(&str, Option<&str>)>> = BTreeMap::new();
   382	
   383	    for arg in split_arg(cmdline) {
   384	        // Everything after "--" goes to init.
   385	        if kcmdline_end {
   386	            result.argv.push(CString::new(arg).unwrap());
   387	            continue;
   388	        }
   389	        if arg == "--" {
   390	            kcmdline_end = true;
   391	            continue;
   392	        }
   393	
   394	        let (key, value) = match arg.find('=') {
   395	            Some(pos) => (&arg[..pos], Some(&arg[pos + 1..])),
   396	            None => (arg, None),
   397	        };
   398	        // Normalize hyphens to underscores (Linux compatibility)
   399	        let normalized = key.replace('-', "_");
   400	        // Group by normalized name, but keep the original key and value for forwarding.
   401	        grouped.entry(normalized).or_default().push((key, value));
   402	    }
   403	
   404	    // Step 2: Build lookup from registered param name to handler.
   405	    let registry: BTreeMap<&str, &KernelParam> = inventory::iter::<KernelParam>
   406	        .into_iter()
   407	        .map(|p| (p.name, p))
   408	        .collect();
   409	
   410	    // Step 3: Dispatch each group to its handler.
   411	    let mut recognized = Vec::new();
   412	    for (name, occurrences) in &grouped {
   413	        if let Some(param) = registry.get(name.as_str()) {
   414	            recognized.push((*param, occurrences));
   415	        } else {
   416	            // Unknown parameter: forward to init
   417	            if name.contains('.') {
   418	                // The entry contains a dot, which is treated as a module argument.
   419	                // Unrecognized module arguments are ignored.
   420	                continue;
   421	            } else if let Some((key, Some(value))) = occurrences.last().copied() {
   422	                // If the entry is not recognized, it is passed to the init process.
   423	                // Pattern 'entry=value' is treated as the init environment.
   424	                let envp_entry = CString::new(key.to_string() + "=" + value).unwrap();
   425	                result.envp.push(envp_entry);
   426	            } else if let Some((key, None)) = occurrences.last().copied() {
   427	                // If the entry is not recognized, it is passed to the init process.
   428	                // Pattern 'entry' without value is treated as the init argument.
   429	                let argv_entry = CString::new(key.to_string()).unwrap();
   430	                result.argv.push(argv_entry);
   431	            } else {
   432	                // This case should not happen since `occurrences` should never be empty.
   433	                debug_assert!(!occurrences.is_empty());
   434	            }
   435	        }
   436	    }
   437	
   438	    // Step 4: Call the setup function for each recognized parameter.
   439	    let (early_params, params): (Vec<_>, Vec<_>) =
   440	        recognized.into_iter().partition(|(p, _)| p.early);
   441	    early_params
   442	        .into_iter()
   443	        .chain(params)
   444	        .for_each(|(param, occurrences)| (param.setup)(occurrences));
   445	
   446	    result
   447	}

    16	/// Linux-style CPU list.
    17	///
    18	/// Examples:
    19	/// - `"1"`
    20	/// - `"1,2,10-20"`
    21	/// - `"100-2000:2/25"` (range with stride and optional group size)
    22	///
    23	/// The stored representation is a list of segments; expansion is optional.
    24	#[derive(Debug, Clone, PartialEq, Eq)]
    25	pub struct CpuList {
    26	    segments: Vec<CpuListSegment>,
    27	}

    29	#[derive(Debug, Clone, PartialEq, Eq)]
    30	pub struct CpuListSegment {
    31	    pub start: u32,
    32	    pub end: u32,
    33	    /// Step within range, default 1.
    34	    pub stride: u32,
    35	    /// Optional group size (the `/N` part). When present, stride selection is
    36	    /// applied within each group window.
    37	    pub group: Option<u32>,
    38	}

    40	/// Linux-style metric-suffixed u64 value.
    41	///
    42	/// Supports binary multiples (KiB-style):
    43	/// - `K` = 1024
    44	/// - `M` = 1024^2
    45	/// - `G` = 1024^3
    46	/// - `T` = 1024^4
    47	/// - `P` = 1024^5
    48	///
    49	/// Case-insensitive.
    50	#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
    51	pub struct MetricU64(pub u64);

    53	impl CpuList {
    54	    pub fn segments(&self) -> &[CpuListSegment] {
    55	        &self.segments
    56	    }
    57	
    58	    pub fn contains(&self, cpu: u32) -> bool {
    59	        self.segments.iter().any(|s| segment_contains(s, cpu))
    60	    }
    61	
    62	    /// Expand to concrete CPU IDs, returning at most `max_elems` elements.
    63	    ///
    64	    /// Note: if the CPU list expands to more than `max_elems`, the result is truncated.
    65	    pub fn expand_bounded(&self, max_elems: usize) -> Result<Vec<u32>, ParamError> {
    66	        if max_elems == 0 {
    67	            return Ok(Vec::new());
    68	        }
    69	
    70	        let mut out = Vec::new();
    71	
    72	        // Helper: push a cpu id; if we reached the bound, stop expansion.
    73	        let push_or_done = |out: &mut Vec<u32>, cpu: u32| -> bool {
    74	            if out.len() >= max_elems {
    75	                return true;
    76	            }
    77	            out.push(cpu);
    78	            out.len() >= max_elems
    79	        };
    80	
    81	        for s in &self.segments {
    82	            if s.stride == 0 {
    83	                return Err(ParamError::InvalidValue);
    84	            }
    85	            if let Some(g) = s.group
    86	                && g == 0
    87	            {
    88	                return Err(ParamError::InvalidValue);
    89	            }
    90	            if s.start > s.end {
    91	                return Err(ParamError::InvalidValue);
    92	            }
    93	
    94	            // Fast path: no group => arithmetic progression from start to end by stride.
    95	            if s.group.is_none() {
    96	                let mut cur = s.start;
    97	                while cur <= s.end {
    98	                    if push_or_done(&mut out, cur) {
    99	                        return Ok(out);
   100	                    }
   101	
   102	                    match cur.checked_add(s.stride) {
   103	                        Some(n) => cur = n,
   104	                        None => break,
   105	                    }
   106	                }
   107	                continue;
   108	            }
   109	
   110	            // Grouped selection:
   111	            // for each group window [start+gb, start+gb+g), emit start+gb+within for within=0,stride,2*stride...
   112	            let g = s.group.unwrap();
   113	            let stride = s.stride;
   114	
   115	            let mut gb: u32 = 0;
   116	            while let Some(v) = s.start.checked_add(gb) {
   117	                let group_start = v;
   118	                if group_start > s.end {
   119	                    break;
   120	                }
   121	
   122	                let mut within: u32 = 0;
   123	                while within < g {
   124	                    let cpu = match group_start.checked_add(within) {
   125	                        Some(v) => v,
   126	                        None => break,
   127	                    };
   128	                    if cpu > s.end {
   129	                        break;
   130	                    }
   131	
   132	                    if push_or_done(&mut out, cpu) {
   133	                        return Ok(out);
   134	                    }
   135	
   136	                    match within.checked_add(stride) {
   137	                        Some(n) => within = n,
   138	                        None => break,
   139	                    }
   140	                }
   141	
   142	                match gb.checked_add(g) {
   143	                    Some(n) => gb = n,
   144	                    None => break,
   145	                }
   146	            }
   147	        }
   148	
   149	        Ok(out)
   150	    }
   151	}

   153	fn segment_contains(s: &CpuListSegment, cpu: u32) -> bool {
   154	    if cpu < s.start || cpu > s.end {
   155	        return false;
   156	    }
   157	    if s.stride == 0 {
   158	        return false;
   159	    }
   160	
   161	    let offset = cpu - s.start;
   162	    if let Some(g) = s.group {
   163	        if g == 0 {
   164	            return false;
   165	        }
   166	        let in_group_offset = offset % g;
   167	        in_group_offset.is_multiple_of(s.stride)
   168	    } else {
   169	        offset.is_multiple_of(s.stride)
   170	    }
   171	}

   173	impl ParseParamValue for CpuList {
   174	    fn parse_param(value: &str) -> Result<Self, ParamError> {
   175	        if value.is_empty() {
   176	            return Err(ParamError::InvalidValue);
   177	        }
   178	
   179	        let mut segments = Vec::new();
   180	        for part in value.split(',') {
   181	            if part.is_empty() {
   182	                return Err(ParamError::InvalidValue);
   183	            }
   184	            segments.push(parse_cpu_segment(part)?);
   185	        }
   186	
   187	        Ok(CpuList { segments })
   188	    }
   189	}
   190	
   191	fn parse_cpu_segment(s: &str) -> Result<CpuListSegment, ParamError> {
   192	    // Grammar (pragmatic):
   193	    //   <range> [":" <stride> ["/" <group>] ]
   194	    // where <range> := <n> | <n> "-" <m>
   195	    let (range_part, tail) = match s.split_once(':') {
   196	        Some((a, b)) => (a, Some(b)),
   197	        None => (s, None),
   198	    };
   199	
   200	    let (start, end) = if let Some((a, b)) = range_part.split_once('-') {
   201	        (parse_u32(a)?, parse_u32(b)?)
   202	    } else {
   203	        let n = parse_u32(range_part)?;
   204	        (n, n)
   205	    };
   206	
   207	    if start > end {
   208	        return Err(ParamError::InvalidValue);
   209	    }
   210	
   211	    let (stride, group) = match tail {
   212	        None => (1u32, None),
   213	        Some(t) => {
   214	            if t.is_empty() {
   215	                return Err(ParamError::InvalidValue);
   216	            }
   217	            if let Some((stride_s, group_s)) = t.split_once('/') {
   218	                let stride = parse_u32(stride_s)?;
   219	                let group = parse_u32(group_s)?;
   220	                (stride, Some(group))
   221	            } else {
   222	                (parse_u32(t)?, None)
   223	            }
   224	        }
   225	    };
   226	
   227	    if stride == 0 {
   228	        return Err(ParamError::InvalidValue);
   229	    }
   230	
   231	    if let Some(g) = group
   232	        && g == 0
   233	    {
   234	        return Err(ParamError::InvalidValue);
   235	    }
   236	
   237	    Ok(CpuListSegment {
   238	        start,
   239	        end,
   240	        stride,
   241	        group,
   242	    })
   243	}

   245	fn parse_u32(s: &str) -> Result<u32, ParamError> {
   246	    if s.is_empty() {
   247	        return Err(ParamError::InvalidValue);
   248	    }
   249	    s.parse::<u32>().map_err(|_| ParamError::InvalidValue)
   250	}

   252	impl ParseParamValue for MetricU64 {
   253	    fn parse_param(value: &str) -> Result<Self, ParamError> {
   254	        if value.is_empty() {
   255	            return Err(ParamError::InvalidValue);
   256	        }
   257	
   258	        let (num_part, suf) = match value.chars().last() {
   259	            Some(c) if c.is_ascii_alphabetic() => (&value[..value.len() - c.len_utf8()], Some(c)),
   260	            _ => (value, None),
   261	        };
   262	
   263	        if num_part.is_empty() {
   264	            return Err(ParamError::InvalidValue);
   265	        }
   266	
   267	        let base: u64 = num_part.parse().map_err(|_| ParamError::InvalidValue)?;
   268	        let mul: u64 = match suf.map(|c| c.to_ascii_uppercase()) {
   269	            None => 1,
   270	            Some('K') => 1024u64,
   271	            Some('M') => 1024u64.pow(2),
   272	            Some('G') => 1024u64.pow(3),
   273	            Some('T') => 1024u64.pow(4),
   274	            Some('P') => 1024u64.pow(5),
   275	            _ => return Err(ParamError::InvalidValue),
   276	        };
   277	
   278	        base.checked_mul(mul)
   279	            .map(MetricU64)
   280	            .ok_or(ParamError::InvalidValue)
   281	    }
   282	}

   290	/// Spins and waits until the timeout occurs or `f` returns `Some(_)`.
   291	//
   292	// TODO: The timeout is relatively large, up to several seconds. Therefore, spinning here is not
   293	// appropriate. The code needs to be refactored to use asynchronous interrupts.
   294	fn spin_wait_until<F, R>(timeout: Timeout, mut f: F) -> Option<R>
   295	where
   296	    F: FnMut() -> Option<R>,
   297	{
   298	    use ostd::arch::{read_tsc, tsc_freq};
   299	
   300	    const MSEC_PER_SEC: u64 = 1000;
   301	
   302	    if let Some(res) = f() {
   303	        return Some(res);
   304	    }
   305	
   306	    let current = read_tsc();
   307	    let distance = tsc_freq() / MSEC_PER_SEC * (timeout as u16 as u64);
   308	    loop {
   309	        if let Some(res) = f() {
   310	            return Some(res);
   311	        }
   312	        if read_tsc().wrapping_sub(current) >= distance {
   313	            return None;
   314	        }
   315	        core::hint::spin_loop();
   316	    }
   317	}

# aster-code-review

Review code against Asterinas's coding guidelines
— the persona-keyed pages under `book/src/to-contribute/coding-guidelines/`
— and write one Markdown review file.
The review is **recall-first**: miss as few real defects as possible.
It makes both objective calls (undeniable bugs) and subjective calls (guideline violations, each grounded in a cited rule).

There are two review modes, both **anchored at the current checkout (HEAD)**:

- **`diff <base>`** — a Git change:
  the **commit series** the branch adds over its merge-base with `<base>`
  — each commit's message *and* its diff,
  so the review covers per-commit intent and commit hygiene, not just the net change.
  (Commit first; uncommitted edits are not reviewed in diff mode.)
- **`files <path[:lines] ...>`**
  — target code: the working-tree contents of the named files,
  optionally narrowed to line ranges.

To review at a specific commit, check it out first (it becomes HEAD).

This skill is agent-agnostic (Claude Code and Codex).
Only step 3's spawn primitive differs between agents;
everything else is identical.

## Interface

However the skill is triggered,
it receives ONE raw argument string that begins with a mode word:

```
diff   <base>              <output> [--overwrite] [--per-persona-context=auto|yes|no]
files  <path[:lines] ...>  <output> [--overwrite] [--per-persona-context=auto|yes|no]
```

- `<base>` (diff) — **required**,
  any ref or SHA;
  reviews the commit series `merge-base(<base>, HEAD)..HEAD` (each commit's message + diff).
- `<path[:lines] ...>` (files) — **required**, one or more targets in the working tree.
  A target is a path, optionally `path:N-M` or `path:N-M,K-L` (1-based, inclusive);
  repeat a path to add ranges.
  Wrap a path in double quotes to allow spaces or colons (`"a: b.rs":10-20`).
- `<output>` — **required, last positional** (`cp src... dest` style);
  refuse to overwrite unless `--overwrite`.
- `--overwrite` — replace the output file if it already exists.
- `--per-persona-context` — `yes`: fan out one isolated agent per persona (best recall).
  `no`: one combined agent reviews all personas (cheaper, lower recall).
  `auto` (default) currently resolves to `yes`;
  it will become a benchmark-driven heuristic.
  Controls step 3 only.

**Do not pre-split the argument string yourself.**
Pass it verbatim, as a single quoted argument,
to `resolve_target.sh` (step 1)
— the script self-tokenizes (whitespace-split except inside double quotes),
which keeps the parse deterministic and identical across agents.

## Pipeline

Run these steps in order.
Steps 1 and 5 are deterministic scripts;
steps 6–8 use the model.

The helper scripts live in the skill's own `scripts/` directory,
at `.agents/skills/aster-code-review/scripts/` inside the repository under review.
**Invoke every script by its absolute path**
— the working directory is the code under review (the repo root), *not* the skill directory,
so a bare `scripts/…` is not found (notably on Codex, which runs commands from the repo root; do not `cd` into the skill dir either — `resolve_target.sh` needs the repo as its cwd).
Shells do not persist between commands,
so **set `SKILL` at the start of each command that uses it** (or inline the `$(git rev-parse …)`):

```sh
SKILL="$(git rev-parse --show-toplevel)/.agents/skills/aster-code-review"; "$SKILL/scripts/resolve_target.sh" '<raw args>'
```

The steps below write `$SKILL/scripts/…` as shorthand for that absolute path.

1. **Resolve the target.**
   `"$SKILL/scripts/resolve_target.sh" '<raw args>'` prints the canonical review input
   — the commit series (each commit's message + diff) in `diff` mode,
   annotated file excerpts in `files` mode;
   save it to a temp file.
   Run it again with `--meta` first (`"$SKILL/scripts/resolve_target.sh" --meta '<raw args>'`) to get
   `mode=`, `base=`/`files=`, `head=`, `branch=`, `output=`, `overwrite=`, `per_persona_context=`;
   add `date=` (today) and an optional `title=` to make the meta file.
   Pass the raw argument string as a single quoted argument
   so the script's tokenizer sees it intact.
2. **Activate personas.**
   Pick which of the five personas run,
   from the reviewed paths — changed paths in `diff` mode,
   named paths in `files` mode (see *Activation*).
3. **Fan out.**
   Spawn the persona passes (see *Spawning*).
   With `per_persona_context` = `yes` or `auto` (the default),
   run **one isolated PASS per activated persona** — best recall.
   With `no`, run **one combined PASS** over all activated personas in a single context
   — cheaper, lower recall.
   Build each pass's prompt deterministically with `"$SKILL/scripts/build_pass_prompt.sh" <input-file> <persona>...`
   — one persona for fan-out, all activated personas for combined
   — and spawn the sub-agent with **that exact text**.
   Each pass returns a JSON array of comments;
   file each under its persona's `<fragdir>/<persona>.json` (the comment's `persona` field says which),
   so step 5 is unchanged.
4. **Collect** the per-persona JSON fragments.
5. **Assemble.**
   `"$SKILL/scripts/assemble_review.sh" [--overwrite] <meta> <fragdir> <output>` performs the deterministic merge (group by persona in fixed order, sort by file→line, drop exact duplicates *within a persona*, write frontmatter, leave a `<!-- SUMMARY -->` placeholder).
   Pass `--overwrite` only if the user gave it;
   otherwise the script refuses to clobber an existing `<output>`.
6. **Verify** (see *Verification*).
7. **Consolidate** (see *Consolidation*).
8. **Summary.**
   Replace `<!-- SUMMARY -->` with a constructive summary over the final comments:
   what the code does well, the top issues ranked by severity,
   any structural recommendations.

## Activation

A persona runs unless the reviewed paths *provably* contain nothing in its remit (reviewed paths = changed paths in `diff` mode, named paths in `files` mode):

- **maintainability, development, security** — any reviewed code.
- **hardware** — a reviewed path is assembly (`*.S`, `*.asm`),
  an architecture directory (`.../arch/...`), or contains `asm!` / `global_asm!`.
- **documentation** — a reviewed path is `book/`, any `*.md`,
  syscall-coverage files (`*.scml`), or a user-facing API surface (a syscall or kernel parameter).

Activation is path-based and deterministic;
do not use a model to triage (a wrongly-skipped persona is a silent recall hole).

## Pass contract

The shared reviewer contract
— the review methodology and the JSON comment schema every pass must follow
— lives in [`scripts/pass_contract.md`](scripts/pass_contract.md),
inlined as the **stable head** of every pass prompt by `build_pass_prompt.sh` (step 3).
Do not paraphrase it into the prompt yourself:
retyping it breaks the byte-identical prefix the prompt cache relies on (see [`execution_model.md`](spec/execution_model.md)).
A pass reads only the persona block(s) it is given (selective exposure),
reviews the **REVIEW INPUT** at the foot of the prompt,
and returns a JSON array of comments per that schema.

## Spawning a pass

Build every pass prompt with `"$SKILL/scripts/build_pass_prompt.sh" <input-file> <persona>...`
and spawn the sub-agent with its **exact** output
— only a script keeps the prompt's stable head (contract + guideline) byte-identical across passes and reviews,
which is what lets the prompt cache reuse it (see [`execution_model.md`](spec/execution_model.md)).

**Default (`per_persona_context` = `yes`/`auto`)**
— one pass per activated persona,
each in a CLEAN context with only its own persona block (selective exposure):

- **Claude Code** — spawn a Task sub-agent per persona.
- **Codex** — run `codex exec "<build_pass_prompt.sh output>"` per persona
  (pass the built PROMPT TEXT as the argument).

**Never spawn a pass by re-running `aster_code_review.sh` / `run_agent.sh`,
nor by re-issuing the skill's own arguments** (e.g. `codex exec … diff <base> <out>`).
A pass is a *reviewer* invocation whose input is the `build_pass_prompt.sh` text
— not another run of this skill.
Re-entering the launcher spawns another orchestrator that spawns another … , an infinite fork bomb;
the launcher now refuses it (`ACR_AGENT_RUNNING`).

Passes are independent;
order does not matter.
Collect each pass's JSON.

**Combined (`per_persona_context` = `no`)**
— build ONE prompt with all activated personas (`"$SKILL/scripts/build_pass_prompt.sh" <input> <p1> <p2> ...`)
and run a single pass;
it reviews through every lens at once and tags each comment with its `persona`.
The input and spawn overhead are paid once,
so it is cheaper
— but a larger shared context dilutes focus,
so it finds fewer defects.
The default stays fan-out:
recall comes first,
and `no` is an explicit, opt-in concession.

## Verification (step 6)

For each comment, isolate the key premise it rests on
— especially an external-system fact (Linux/POSIX behaviour, the System V ABI, Rust semantics).
Try to **refute** it:
re-read the cited code and consult an authoritative source.
Assign a verdict:

- **confirmed** — keep the comment unchanged.
- **uncertain** — keep it, but prefix `problem` with `(unverified) `.
- **refuted** — remove the comment,
  and append it to a `## Retracted by verification` list at the foot of the file with a one-line reason.

Remove **only** on confident refutation;
an unsure check is `uncertain`, not `refuted`.
This is the only step that may remove a comment, and only false positives.

## Consolidation (step 7)

Find clusters of comments that share one root cause or one fix
(e.g. several manual lock/unlock pairs that all want RAII).
For each cluster, write a single unified fix
and repoint each member's `**Fix.**` at it ("Shared with the other `raii` comments: …").
**Never remove a comment**
— every symptom stays at its own location.

## Output format

The assembled file is:
frontmatter (`date`, `mode`, `base` or `files`, `head`, `branch`, optional `title`),
a `# Summary`,
then a `## <section>` per persona in the order **Maintainability, Correctness, Security, Hardware, Documentation** (Correctness is the Development persona's section).
Each comment is a `### \`file\` line N` subsection:
a quoted ` ```diff ` snippet,
then a prose line `` `<grounding>` (<severity>): <problem> ``,
then a `**Fix.**` paragraph.
Do not restructure what the script emits;
only fill the summary and apply the verify/consolidate edits.

   254	        if !unsupported_flags.is_empty() {
   255	            warn!("contains unsupported clone flags: {:?}", unsupported_flags);
   256	        }
   257	        Ok(())
   258	    }
   259	}

   261	/// Clone a child thread or child process.
   262	///
   263	/// FIXME: currently, the child process or thread will be scheduled to run at once,
   264	/// but this may not be the expected behavior.
   265	pub fn clone_child(
   266	    ctx: &Context,
   267	    parent_context: &UserContext,
   268	    clone_args: CloneArgs,
   269	) -> Result<Tid> {
   270	    clone_args.check(ctx)?;
   271	
   272	    if clone_args.flags.contains(CloneFlags::CLONE_THREAD) {
   273	        let child_task = clone_child_task(ctx, parent_context, clone_args)?;
   274	        let child_thread = child_task.as_thread().unwrap();
   275	        child_thread.run();
   276	
   277	        let child_tid = child_thread.as_posix_thread().unwrap().tid();
   278	        Ok(child_tid)
   279	    } else {
   280	        let child_process = clone_child_process(ctx, parent_context, clone_args)?;
   281	        if clone_args.flags.contains(CloneFlags::CLONE_VFORK) {
   282	            child_process.status().set_vfork_child(true);
   283	        }
   284	
   285	        child_process.run();
   286	
   287	        if child_process.status().is_vfork_child() {
   288	            let cond = || (!child_process.status().is_vfork_child()).then_some(());
   289	            let current = ctx.process.as_ref();
   290	            current.children_wait_queue().wait_until(cond);
   291	        }
   292	
   293	        let child_pid = child_process.pid();
   294	        FORKS_COUNTER
   295	            .get()
   296	            .unwrap()
   297	            .add_on_cpu(CpuId::current_racy(), 1);
   298	        Ok(child_pid)
   299	    }
   300	}

   302	fn clone_child_task(
   303	    ctx: &Context,
   304	    parent_context: &UserContext,
   305	    clone_args: CloneArgs,
   306	) -> Result<Arc<Task>> {
   307	    let clone_flags = clone_args.flags;
   308	
   309	    let Context {
   310	        process,
   311	        thread_local,
   312	        posix_thread,
   313	        ..
   314	    } = ctx;
   315	
   316	    // Clone system V semaphore
   317	    clone_sysvsem(clone_flags)?;
   318	
   319	    // Clone file table
   320	    let child_file_table = clone_files(thread_local.borrow_file_table().unwrap(), clone_flags);
   321	
   322	    // Clone fs
   323	    let child_fs = clone_fs(&thread_local.borrow_fs(), clone_flags);
   324	
   325	    // Clone FPU context
   326	    let child_fpu_context = thread_local.fpu().clone_context();
   327	
   328	    // Clone namespaces
   329	    let child_user_ns = thread_local.borrow_user_ns().clone();
   330	    let child_ns_proxy = clone_ns_proxy(
   331	        thread_local.borrow_ns_proxy().unwrap(),
   332	        &child_user_ns,
   333	        clone_flags,
   334	        posix_thread,
   335	    )?;
   336	
   337	    if clone_flags.contains(CloneFlags::CLONE_NEWNS) {
   338	        child_fs
   339	            .resolver()
   340	            .write()
   341	            .switch_to_mnt_ns(child_ns_proxy.mnt_ns())?;
   342	    }
   343	
   344	    let child_user_ctx = Box::new(clone_user_ctx(
   345	        parent_context,
   346	        clone_args.stack,
   347	        clone_args.stack_size,
   348	        clone_args.tls,
   349	        clone_flags,
   350	    ));
   351	
   352	    // Inherit sigmask from current thread
   353	    let sig_mask = posix_thread.sig_mask().load(Ordering::Relaxed).into();
   354	
   355	    // Inherit the thread name.
   356	    let thread_name = posix_thread.thread_name().lock().as_ref().cloned();
   357	
   358	    let child_tid = allocate_posix_tid();
   359	    let child_task = {
   360	        let credentials = {
   361	            let credentials = ctx.posix_thread.credentials();
   362	            Credentials::new_from(&credentials)
   363	        };
   364	
   365	        let mut thread_builder = PosixThreadBuilder::new(child_tid, child_user_ctx, credentials)
   366	            .process(posix_thread.weak_process())
   367	            .thread_name(thread_name)
   368	            .sig_mask(sig_mask)
   369	            .file_table(child_file_table)
   370	            .fs(child_fs)
   371	            .fpu_context(child_fpu_context)
   372	            .user_ns(child_user_ns)
   373	            .ns_proxy(child_ns_proxy);
   374	
   375	        // Deal with SETTID/CLEARTID flags
   376	        clone_parent_settid(child_tid, clone_args.parent_tid, clone_flags)?;
   377	        thread_builder = clone_child_cleartid(thread_builder, clone_args.child_tid, clone_flags);
   378	        thread_builder = clone_child_settid(thread_builder, clone_args.child_tid, clone_flags);
   379	
   380	        thread_builder.build()
   381	    };
   382	
   383	    process
   384	        .tasks()
   385	        .lock()
   386	        .insert(child_task.clone())
   387	        .map_err(|_| Error::with_message(Errno::EINTR, "the process has exited"))?;
   388	
   389	    Ok(child_task)
   390	}

   392	fn clone_child_process(
   393	    ctx: &Context,
   394	    parent_context: &UserContext,
   395	    clone_args: CloneArgs,
   396	) -> Result<Arc<Process>> {
   397	    let Context {
   398	        process,
   399	        thread_local,
   400	        posix_thread,
   401	        ..
   402	    } = ctx;
   403	
   404	    let clone_flags = clone_args.flags;
   405	
   406	    // Clone the virtual memory space
   407	    let child_process_vm = {
   408	        let parent_process_vm = process.vm();
   409	        clone_vm(parent_process_vm, clone_flags)?
   410	    };
   411	
   412	    // Clone the user context
   413	    let child_user_ctx = Box::new(clone_user_ctx(
   414	        parent_context,
   415	        clone_args.stack,
   416	        clone_args.stack_size,
   417	        clone_args.tls,
   418	        clone_flags,
   419	    ));
   420	
   421	    // Clone the file table
   422	    let child_file_table = clone_files(thread_local.borrow_file_table().unwrap(), clone_flags);
   423	
   424	    // Clone the filesystem information
   425	    let child_fs = clone_fs(&thread_local.borrow_fs(), clone_flags);
   426	
   427	    // Clone signal dispositions
   428	    let child_sig_dispositions = clone_sighand(process.sig_dispositions(), clone_flags);
   429	
   430	    // Clone System V semaphore
   431	    clone_sysvsem(clone_flags)?;
   432	
   433	    // Clone FPU context
   434	    let child_fpu_context = thread_local.fpu().clone_context();
   435	
   436	    // Clone the namespaces
   437	    let child_user_ns = clone_user_ns(clone_flags, thread_local)?;
   438	    let child_ns_proxy = clone_ns_proxy(
   439	        thread_local.borrow_ns_proxy().unwrap(),
   440	        &child_user_ns,
   441	        clone_flags,
   442	        posix_thread,
   443	    )?;
   444	
   445	    if clone_flags.contains(CloneFlags::CLONE_NEWNS) {
   446	        child_fs
   447	            .resolver()
   448	            .write()
   449	            .switch_to_mnt_ns(child_ns_proxy.mnt_ns())?;
   450	    }
   451	
   452	    // Inherit the parent's signal mask
   453	    let child_sig_mask = posix_thread.sig_mask().load(Ordering::Relaxed).into();
   454	
   455	    // Inherit the parent's resource limits
   456	    let child_resource_limits = process.resource_limits().clone();
   457	
   458	    // Inherit the parent's nice value
   459	    let child_nice = process.nice().load(Ordering::Relaxed);
   460	
   461	    // Inherit the parent's OOM score adjustment
   462	    let child_oom_score_adj = process.oom_score_adj().load(Ordering::Relaxed);
   463	
   464	    let child_tid = allocate_posix_tid();
   465	
   466	    let child = {
   467	        let child_elf_path = process.executable_path();
   468	        let mut child_thread_builder = {
   469	            let child_thread_name = ThreadName::new_from_executable_path(&child_elf_path)?;
   470	
   471	            let credentials = {
   472	                let credentials = ctx.posix_thread.credentials();
   473	                Credentials::new_from(&credentials)
   474	            };
   475	
   476	            PosixThreadBuilder::new(child_tid, child_user_ctx, credentials)
   477	                .thread_name(Some(child_thread_name))
   478	                .sig_mask(child_sig_mask)
   479	                .file_table(child_file_table)
   480	                .fs(child_fs)
   481	                .fpu_context(child_fpu_context)
   482	                .user_ns(child_user_ns.clone())
   483	                .ns_proxy(child_ns_proxy)
   484	        };
   485	
   486	        // Deal with SETTID/CLEARTID flags
   487	        clone_parent_settid(child_tid, clone_args.parent_tid, clone_flags)?;
   488	        child_thread_builder =
   489	            clone_child_cleartid(child_thread_builder, clone_args.child_tid, clone_flags);
   490	        child_thread_builder =
   491	            clone_child_settid(child_thread_builder, clone_args.child_tid, clone_flags);
   492	
   493	        create_child_process(
   494	            child_tid,
   495	            &child_elf_path,
   496	            child_process_vm,
   497	            child_resource_limits,
   498	            child_nice,
   499	            child_oom_score_adj,
   500	            child_sig_dispositions,
   501	            child_user_ns,
   502	            child_thread_builder,
   503	        )
   504	    };
   505	
   506	    clone_pidfd(ctx, &child, clone_flags, clone_args.pidfd)?;
   507	
   508	    if let Some(sig) = clone_args.exit_signal {
   509	        child.set_exit_signal(sig);
   510	    };
   511	
   512	    // Sets parent process and group for child process.
   513	    set_parent_and_group(clone_flags, process, &child);
   514	
   515	    Ok(child)
   516	}

   555	/// Clone child process vm. If CLONE_VM is set, both threads share the same root vmar.
   556	/// Otherwise, fork a new copy-on-write vmar.
   557	fn clone_vm(parent_process_vm: &ProcessVm, clone_flags: CloneFlags) -> Result<ProcessVm> {
   558	    if clone_flags.contains(CloneFlags::CLONE_VM) {
   559	        Ok(parent_process_vm.clone())
   560	    } else {
   561	        ProcessVm::fork_from(parent_process_vm)
   562	    }
   563	}

   565	fn clone_user_ctx(
   566	    parent_context: &UserContext,
   567	    new_sp: u64,
   568	    stack_size: Option<NonZeroU64>,
   569	    tls: u64,
   570	    clone_flags: CloneFlags,
   571	) -> UserContext {
   572	    let mut child_context = parent_context.clone();
   573	    // The return value of child thread is zero
   574	    child_context.set_syscall_ret(0);
   575	
   576	    if new_sp != 0 {
   577	        // If stack size is not 0, the `new_sp` points to the BOTTOMMOST byte of stack.
   578	        if let Some(size) = stack_size {
   579	            child_context.set_stack_pointer((new_sp + size.get()) as usize)
   580	        }
   581	        // If stack size is 0, the new_sp points to the TOPMOST byte of stack.
   582	        else {
   583	            child_context.set_stack_pointer(new_sp as usize);
   584	        }
   585	    }
   586	    if clone_flags.contains(CloneFlags::CLONE_SETTLS) {
   587	        child_context.set_tls_pointer(tls as usize);
   588	    }
   589	
   590	    child_context
   591	}

   631	fn clone_pidfd(
   632	    ctx: &Context,
   633	    child: &Arc<Process>,
   634	    clone_flags: CloneFlags,
   635	    pidfd_addr: Option<Vaddr>,
   636	) -> Result<()> {
   637	    if !clone_flags.contains(CloneFlags::CLONE_PIDFD) {
   638	        return Ok(());
   639	    }
   640	
   641	    let pidfd_addr = pidfd_addr.unwrap();
   642	
   643	    let fd = {
   644	        let pid_file = PidFile::new(child.clone(), false);
   645	        let file_table = ctx.thread_local.borrow_file_table();
   646	        let mut file_table_locked = file_table.unwrap().write();
   647	        file_table_locked.insert(Arc::new(pid_file), FdFlags::CLOEXEC)
   648	    };
   649	
   650	    // Since `write_val` may sleep, we cannot hold the file table lock during its execution.
   651	    // FIXME: Should we remove the file from the file table if the write operation fails?
   652	    match ctx.user_space().write_val(pidfd_addr, &fd) {
   653	        Ok(()) => Ok(()),
   654	        Err(e) => {
   655	            let file_table = ctx.thread_local.borrow_file_table();
   656	            let mut file_table_locked = file_table.unwrap().write();
   657	            file_table_locked.close_file(fd);
   658	            Err(e)
   659	        }
   660	    }
   661	}

   686	#[expect(clippy::too_many_arguments)]
   687	fn create_child_process(
   688	    pid: Pid,
   689	    executable_path: &str,
   690	    process_vm: ProcessVm,
   691	    resource_limits: ResourceLimits,
   692	    nice: Nice,
   693	    oom_score_adj: i16,
   694	    sig_dispositions: Arc<Mutex<SigDispositions>>,
   695	    user_ns: Arc<UserNamespace>,
   696	    thread_builder: PosixThreadBuilder,
   697	) -> Arc<Process> {
   698	    let child_proc = Process::new(
   699	        pid,
   700	        executable_path.to_string(),
   701	        process_vm,
   702	        resource_limits,
   703	        nice,
   704	        oom_score_adj,
   705	        sig_dispositions,
   706	        user_ns,
   707	    );
   708	
   709	    let child_task = thread_builder.process(Arc::downgrade(&child_proc)).build();
   710	    child_proc.tasks().lock().insert(child_task).unwrap();
   711	
   712	    child_proc
   713	}

   715	fn set_parent_and_group(clone_flags: CloneFlags, parent: &Arc<Process>, child: &Arc<Process>) {
   716	    loop {
   717	        let real_parent = clone_parent(clone_flags, parent);
   718	
   719	        // Lock the parent's children before checking its status.
   720	        let mut children_mut = real_parent.children().lock();
   721	
   722	        let Some(children_mut) = children_mut.as_mut() else {
   723	            // The real parent is concurrently exiting group.
   724	            // The children have been cleared,
   725	            // so the retrial will see an up-to-date real parent.
   726	            continue;
   727	        };
   728	
   729	        // Lock order: children of process -> parent of process
   730	        child.parent().lock().set_process(&real_parent);
   731	
   732	        // Update `has_child_subreaper` for the child process to
   733	        // make sure the `has_child_subreaper` state of the child process
   734	        // will be consistent with its parent.
   735	        if real_parent.has_child_subreaper.load(Ordering::Relaxed) {
   736	            child.has_child_subreaper.store(true, Ordering::Relaxed);
   737	        }
   738	
   739	        // Lock order: children of process -> process table
   740	        // -> group of process -> group inner
   741	
   742	        let mut process_table_mut = process_table::process_table_mut();
   743	
   744	        let process_group_mut = parent.process_group.lock();
   745	
   746	        let process_group = process_group_mut.upgrade().unwrap();
   747	        let mut process_group_inner = process_group.lock();
   748	
   749	        // Put the child process in the parent's process group
   750	        process_group_inner.insert_process(child.clone());
   751	        *child.process_group.lock() = Arc::downgrade(&process_group);
   752	
   753	        // Put the child process in the parent's `children` field
   754	        children_mut.insert(child.pid(), child.clone());
   755	
   756	        // Put the child process in the global table
   757	        process_table_mut.insert(child.pid(), child.clone());
   758	
   759	        return;
   760	    }
   761	}
   762	
   763	fn clone_parent(clone_flags: CloneFlags, current: &Arc<Process>) -> Cow<'_, Arc<Process>> {
   764	    if clone_flags.contains(CloneFlags::CLONE_PARENT) {
   765	        // The parent process of the current process cannot be `None`, since we have checked that
   766	        // the current process is not the init process.
   767	        Cow::Owned(current.parent().lock().process().upgrade().unwrap())
   768	    } else {
   769	        Cow::Borrowed(current)
   770	    }
   771	}

    13	// The order of arguments for clone differs in different architecture.
    14	// This order we use here is the order for x86_64. See https://man7.org/linux/man-pages/man2/clone.2.html.
    15	pub fn sys_clone(
    16	    clone_flags: u64,
    17	    new_sp: u64,
    18	    parent_tidptr: Vaddr,
    19	    child_tidptr: Vaddr,
    20	    tls: u64,
    21	    ctx: &Context,
    22	    parent_context: &UserContext,
    23	) -> Result<SyscallReturn> {
    24	    let args = CloneArgs::for_clone(clone_flags, parent_tidptr, child_tidptr, tls, new_sp)?;
    25	    debug!("flags = {:?}, child_stack_ptr = 0x{:x}, parent_tid_ptr = 0x{:x?}, child tid ptr = 0x{:x}, tls = 0x{:x}", args.flags, args.stack, args.parent_tid, args.child_tid, args.tls);
    26	    let child_pid = clone_child(ctx, parent_context, args)?;
    27	    Ok(SyscallReturn::Return(child_pid as _))
    28	}

    30	pub fn sys_clone3(
    31	    clong_args_addr: Vaddr,
    32	    size: usize,
    33	    ctx: &Context,
    34	    parent_context: &UserContext,
    35	) -> Result<SyscallReturn> {
    36	    trace!(
    37	        "clone args addr = 0x{:x}, size = 0x{:x}",
    38	        clong_args_addr,
    39	        size
    40	    );
    41	    if size != size_of::<Clone3Args>() {
    42	        return_errno_with_message!(Errno::EINVAL, "invalid size");
    43	    }
    44	
    45	    let clone_args = {
    46	        let args: Clone3Args = ctx.user_space().read_val(clong_args_addr)?;
    47	        trace!("clone3 args = {:x?}", args);
    48	        CloneArgs::try_from(args)?
    49	    };
    50	    debug!("clone args = {:x?}", clone_args);
    51	
    52	    let child_pid = clone_child(ctx, parent_context, clone_args)?;
    53	    trace!("child pid = {}", child_pid);
    54	    Ok(SyscallReturn::Return(child_pid as _))
    55	}

    62	    /// Where to store PID file descriptor
    63	    pidfd: u64,
    64	    /// Where to store child TID in child's memory
    65	    child_tid: u64,
    66	    ///  Where to store child TID in parent's memory
    67	    parent_tid: u64,
    68	    /// Signal to deliver to parent on child termination
    69	    exit_signal: u64,
    70	    /// Pointer to lowest byte of stack
    71	    stack: u64,
    72	    /// Size of stack
    73	    stack_size: u64,
    74	    /// Location of new TLS
    75	    tls: u64,
    76	    /// Pointer to a pid_t array
    77	    set_tid: u64,
    78	    /// Number of elements in set_tid
    79	    set_tid_size: u64,
    80	    /// File descriptor for target cgroup of child
    81	    cgroup: u64,
    82	}

    84	impl TryFrom<Clone3Args> for CloneArgs {
    85	    type Error = Error;
    86	
    87	    fn try_from(value: Clone3Args) -> Result<Self> {
    88	        // TODO: Deal with set_tid, set_tid_size, cgroup
    89	        if value.set_tid != 0 || value.set_tid_size != 0 {
    90	            warn!("set_tid is not supported");
    91	        }
    92	
    93	        if value.cgroup != 0 {
    94	            warn!("cgroup is not supported");
    95	        }
    96	
    97	        let flags = CloneFlags::from_bits(value.flags as u32)
    98	            .ok_or_else(|| Error::with_message(Errno::EINVAL, "invalid clone flags"))?;
    99	        let exit_signal =
   100	            (value.exit_signal != 0).then(|| SigNum::from_u8(value.exit_signal as u8));
   101	
   102	        if flags.intersects(CloneFlags::CLONE_PARENT | CloneFlags::CLONE_THREAD)
   103	            && exit_signal.is_some()
   104	        {
   105	            return_errno_with_message!(
   106	                Errno::EINVAL,
   107	                "`CLONE_PARENT` and  `CLONE_THREAD` cannot be used if the exit signal is specified"
   108	            )
   109	        }
   110	
   111	        Ok(Self {
   112	            flags,
   113	            pidfd: Some(value.pidfd as Vaddr),
   114	            child_tid: value.child_tid as _,
   115	            parent_tid: Some(value.parent_tid as _),
   116	            exit_signal,
   117	            stack: value.stack,
   118	            stack_size: NonZeroU64::new(value.stack_size),
   119	            tls: value.tls,
   120	            _set_tid: Some(value.set_tid),
   121	            _set_tid_size: Some(value.set_tid_size),
   122	            _cgroup: Some(value.cgroup),
   123	        })
   124	    }
   125	}

     8	/// Exits the current POSIX process.
     9	///
    10	/// This is for internal use. Do NOT call this directly. When the last thread in the process exits,
    11	/// [`do_exit`] or [`do_exit_group`] will invoke this method automatically.
    12	///
    13	/// [`do_exit`]: crate::process::posix_thread::do_exit
    14	/// [`do_exit_group`]: crate::process::posix_thread::do_exit_group
    15	pub(super) fn exit_process(current_process: &Process) {
    16	    current_process.status().set_zombie();
    17	    current_process.status().set_vfork_child(false);
    18	
    19	    // Drop fields in `Process`.
    20	    current_process.lock_root_vmar().set_vmar(None);
    21	
    22	    current_process.pidfile_pollee.notify(IoEvents::IN);
    23	
    24	    send_parent_death_signal(current_process);
    25	
    26	    move_children_to_reaper_process(current_process);
    27	
    28	    send_child_death_signal(current_process);
    29	}
    30	
    31	/// Sends parent-death signals to the children.
    32	//
    33	// FIXME: According to the Linux implementation, the signal should be sent when the POSIX thread
    34	// that created the child exits, not when the whole process exits. For more details, see the
    35	// "CAVEATS" section in <https://man7.org/linux/man-pages/man2/pr_set_pdeathsig.2const.html>.
    36	fn send_parent_death_signal(current_process: &Process) {
    37	    let current_children = current_process.children().lock();
    38	    for child in current_children.as_ref().unwrap().values() {
    39	        let Some(signum) = child.parent_death_signal() else {
    40	            continue;
    41	        };
    42	
    43	        // FIXME: Set `si_pid` in the `siginfo_t` argument.
    44	        let signal = KernelSignal::new(signum);
    45	        child.enqueue_signal(signal);
    46	    }
    47	}
    48	
    49	/// Finds a reaper process for `current_process`.
    50	///
    51	/// If there is no reaper process for `current_process`, returns `None`.
    52	fn find_reaper_process(current_process: &Process) -> Option<Arc<Process>> {
    53	    let mut parent = current_process.parent().lock().process();
    54	
    55	    while let Some(process) = parent.upgrade() {
    56	        if is_init_process(&process) {
    57	            return Some(process);
    58	        }
    59	
    60	        if !process.has_child_subreaper.load(Ordering::Acquire) {
    61	            return None;
    62	        }
    63	
    64	        let is_reaper = process.is_child_subreaper();
    65	        let is_zombie = process.status().is_zombie();
    66	        if is_reaper && !is_zombie {
    67	            return Some(process);
    68	        }
    69	
    70	        parent = process.parent().lock().process();
    71	    }
    72	
    73	    None
    74	}
    75	
    76	/// Moves the children of `current_process` to be the children of `reaper_process`.
    77	///
    78	/// If the `reaper_process` is zombie, returns `Err(())`.
    79	fn move_process_children(
    80	    current_process: &Process,
    81	    reaper_process: &Arc<Process>,
    82	) -> core::result::Result<(), ()> {
    83	    // Take the lock first to avoid the race when the `reaper_process` is exiting concurrently.
    84	    let mut reaper_process_children = reaper_process.children().lock();
    85	
    86	    let Some(reaper_process_children) = reaper_process_children.as_mut() else {
    87	        // The reaper process has exited, and it is not the init process
    88	        // (since we never clear the init process's children).
    89	        return Err(());
    90	    };
    91	
    92	    // Lock order: children of process -> parent of process
    93	    // We holds the lock of children while update the children's parents.
    94	    // This ensures when dealing with CLONE_PARENT,
    95	    // the retrial will see an up-to-date real parent.
    96	    let mut current_children = current_process.children().lock();
    97	    for child_process in current_children.as_mut().unwrap().values() {
    98	        let mut parent = child_process.parent.lock();
    99	        reaper_process_children.insert(child_process.pid(), child_process.clone());
   100	        parent.set_process(reaper_process);
   101	    }
   102	    *current_children = None;
   103	
   104	    Ok(())
   105	}
   106	
   107	/// Moves the children to a reaper process.
   108	fn move_children_to_reaper_process(current_process: &Process) {
   109	    if is_init_process(current_process) {
   110	        return;
   111	    }
   112	
   113	    while let Some(reaper_process) = find_reaper_process(current_process) {
   114	        if move_process_children(current_process, &reaper_process).is_ok() {
   115	            return;
   116	        }
   117	    }
   118	
   119	    let Some(init_process) = get_init_process() else {
   120	        return;
   121	    };
   122	
   123	    let _ = move_process_children(current_process, &init_process);
   124	}
   125	
   126	/// Sends a child-death signal to the parent.
   127	fn send_child_death_signal(current_process: &Process) {
   128	    let Some(parent) = current_process.parent().lock().process().upgrade() else {
   129	        return;
   130	    };
   131	
   132	    if let Some(signal) = current_process.exit_signal().map(KernelSignal::new) {
   133	        parent.enqueue_signal(signal);
   134	    };
   135	    parent.children_wait_queue().wake_all();
   136	}

   139	
   140	/// Gets the init process
   141	fn get_init_process() -> Option<Arc<Process>> {
   142	    process_table::get_process(INIT_PROCESS_PID)
   143	}
   144	
   145	fn is_init_process(process: &Process) -> bool {
   146	    process.pid() == INIT_PROCESS_PID

   360	    /// Moves the process to the new session.
   361	    ///
   362	    /// This method will create a new process group in a new session, move the process to the new
   363	    /// session, and return the session ID (which is equal to the process ID and the process group
   364	    /// ID).
   365	    ///
   366	    /// # Errors
   367	    ///
   368	    /// This method will return `EPERM` if an existing process group has the same identifier as the
   369	    /// process ID. This means that the process is or was a process group leader and that the
   370	    /// process group is still alive.
   371	    pub fn to_new_session(self: &Arc<Self>) -> Result<Sid> {
   372	        // Lock order: session table -> group table -> group of process
   373	        // -> group inner -> session inner
   374	        let mut session_table_mut = process_table::session_table_mut();
   375	        let mut group_table_mut = process_table::group_table_mut();
   376	
   377	        if session_table_mut.contains_key(&self.pid) {
   378	            // FIXME: According to the Linux implementation, this check should be removed, so we'll
   379	            // return `EPERM` due to hitting the following check. However, we need to work around a
   380	            // gVisor bug. The upstream gVisor has fixed the issue in:
   381	            // <https://github.com/google/gvisor/commit/582f7bf6c0ccccaeb1215a232709df38d5d409f7>.
   382	            return Ok(self.pid);
   383	        }
   384	        if group_table_mut.contains_key(&self.pid) {
   385	            return_errno_with_message!(
   386	                Errno::EPERM,
   387	                "a process group leader cannot be moved to a new session"
   388	            );
   389	        }
   390	
   391	        let mut process_group_mut = self.process_group.lock();
   392	
   393	        self.clear_old_group_and_session(
   394	            &mut process_group_mut,
   395	            &mut session_table_mut,
   396	            &mut group_table_mut,
   397	        );
   398	
   399	        Ok(self.set_new_session(
   400	            &mut process_group_mut,
   401	            &mut session_table_mut,
   402	            &mut group_table_mut,
   403	        ))
   404	    }

   406	    pub(super) fn clear_old_group_and_session(
   407	        &self,
   408	        process_group_mut: &mut MutexGuard<Weak<ProcessGroup>>,
   409	        session_table_mut: &mut MutexGuard<BTreeMap<Sid, Arc<Session>>>,
   410	        group_table_mut: &mut MutexGuard<BTreeMap<Pgid, Arc<ProcessGroup>>>,
   411	    ) {
   412	        let process_group = process_group_mut.upgrade().unwrap();
   413	        let mut process_group_inner = process_group.lock();
   414	        let session = process_group.session().unwrap();
   415	        let mut session_inner = session.lock();
   416	
   417	        // Remove the process from the process group.
   418	        process_group_inner.remove_process(&self.pid);
   419	        if process_group_inner.is_empty() {
   420	            group_table_mut.remove(&process_group.pgid());
   421	
   422	            // Remove the process group from the session.
   423	            session_inner.remove_process_group(&process_group.pgid());
   424	            if session_inner.is_empty() {
   425	                session_table_mut.remove(&session.sid());
   426	            }
   427	        }
   428	
   429	        **process_group_mut = Weak::new();
   430	    }

   432	    fn set_new_session(
   433	        self: &Arc<Self>,
   434	        process_group_mut: &mut MutexGuard<Weak<ProcessGroup>>,
   435	        session_table_mut: &mut MutexGuard<BTreeMap<Sid, Arc<Session>>>,
   436	        group_table_mut: &mut MutexGuard<BTreeMap<Pgid, Arc<ProcessGroup>>>,
   437	    ) -> Sid {
   438	        let (session, process_group) = Session::new_pair(self.clone());
   439	        let sid = session.sid();
   440	
   441	        **process_group_mut = Arc::downgrade(&process_group);
   442	
   443	        // Insert the new session and the new process group to the global table.
   444	        session_table_mut.insert(session.sid(), session);
   445	        group_table_mut.insert(process_group.pgid(), process_group);
   446	
   447	        sid
   448	    }

   450	    /// Moves the process itself or its child process to another process group.
   451	    ///
   452	    /// The process to be moved is specified with the process ID `pid`; `self` is used only for
   453	    /// permission checking purposes (see the Errors section below), which is typically
   454	    /// `current!()` when implementing system calls.
   455	    ///
   456	    /// If `pgid` is equal to the process ID, a new process group with the given PGID will be
   457	    /// created (if it does not already exist). Then, the process will be moved to the process
   458	    /// group with the given PGID, if the process group exists and belongs to the same session as
   459	    /// the given process.
   460	    ///
   461	    /// # Errors
   462	    ///
   463	    /// This method will return `ESRCH` in following cases:
   464	    ///  * The process specified by `pid` does not exist;
   465	    ///  * The process specified by `pid` is neither `self` or a child process of `self`.
   466	    ///
   467	    /// This method will return `EPERM` in following cases:
   468	    ///  * The process is not in the same session as `self`;
   469	    ///  * The process is a session leader, but the given PGID is not the process's PID/PGID;
   470	    ///  * The process group already exists, but the group does not belong to the same session;
   471	    ///  * The process group does not exist, but `pgid` is not equal to the process ID.
   472	    pub fn move_process_to_group(&self, pid: Pid, pgid: Pgid) -> Result<()> {
   473	        // Lock order: group table -> process table -> group of process
   474	        // -> group inner -> session inner
   475	        let group_table_mut = process_table::group_table_mut();
   476	        let process_table_mut = process_table::process_table_mut();
   477	
   478	        let process = process_table_mut.get(pid).ok_or(Error::with_message(
   479	            Errno::ESRCH,
   480	            "the process to set the PGID does not exist",
   481	        ))?;
   482	
   483	        let current_session = if self.pid == process.pid() {
   484	            // There is no need to check if the session is the same in this case.
   485	            None
   486	        } else if self.pid == process.parent().pid() {
   487	            // FIXME: If the child process has called `execve`, we should fail with `EACCESS`.
   488	
   489	            // Immediately release the `self.process_group` lock to avoid deadlocks. Race
   490	            // conditions don't matter because this is used for comparison purposes only.
   491	            Some(
   492	                self.process_group
   493	                    .lock()
   494	                    .upgrade()
   495	                    .unwrap()
   496	                    .session()
   497	                    .unwrap(),
   498	            )
   499	        } else {
   500	            return_errno_with_message!(
   501	                Errno::ESRCH,
   502	                "the process to set the PGID is neither the current process nor its child process"
   503	            );
   504	        };
   505	
   506	        if let Some(new_process_group) = group_table_mut.get(&pgid).cloned() {
   507	            process.to_existing_group(current_session, group_table_mut, new_process_group)
   508	        } else if pgid == process.pid() {
   509	            process.to_new_group(current_session, group_table_mut)
   510	        } else {
   511	            return_errno_with_message!(Errno::EPERM, "the new process group does not exist");
   512	        }
   513	    }

   515	    /// Moves the process to an existing group.
   516	    fn to_existing_group(
   517	        self: &Arc<Self>,
   518	        current_session: Option<Arc<Session>>,
   519	        mut group_table_mut: MutexGuard<BTreeMap<Pgid, Arc<ProcessGroup>>>,
   520	        new_process_group: Arc<ProcessGroup>,
   521	    ) -> Result<()> {
   522	        let mut process_group_mut = self.process_group.lock();
   523	        let process_group = process_group_mut.upgrade().unwrap();
   524	
   525	        let session = process_group.session().unwrap();
   526	        if session.sid() == self.pid {
   527	            return_errno_with_message!(
   528	                Errno::EPERM,
   529	                "a session leader cannot be moved to a new process group"
   530	            );
   531	        }
   532	        if !Arc::ptr_eq(&session, &new_process_group.session().unwrap()) {
   533	            return_errno_with_message!(
   534	                Errno::EPERM,
   535	                "the new process group does not belong to the same session"
   536	            );
   537	        }
   538	        if current_session.is_some_and(|current| !Arc::ptr_eq(&current, &session)) {
   539	            return_errno_with_message!(Errno::EPERM, "the process belongs to a different session");
   540	        }
   541	
   542	        // Lock order: group with a smaller PGID -> group with a larger PGID
   543	        let (mut process_group_inner, mut new_group_inner) =
   544	            match process_group.pgid().cmp(&new_process_group.pgid()) {
   545	                core::cmp::Ordering::Less => {
   546	                    let process_group_inner = process_group.lock();
   547	                    let new_group_inner = new_process_group.lock();
   548	                    (process_group_inner, new_group_inner)
   549	                }
   550	                core::cmp::Ordering::Greater => {
   551	                    let new_group_inner = new_process_group.lock();
   552	                    let process_group_inner = process_group.lock();
   553	                    (process_group_inner, new_group_inner)
   554	                }
   555	                core::cmp::Ordering::Equal => return Ok(()),
   556	            };
   557	        let mut session_inner = session.lock();
   558	
   559	        // Remove the process from the old process group
   560	        process_group_inner.remove_process(&self.pid);
   561	        if process_group_inner.is_empty() {
   562	            group_table_mut.remove(&process_group.pgid());
   563	            session_inner.remove_process_group(&process_group.pgid());
   564	        }
   565	
   566	        // Insert the process to the new process group
   567	        new_group_inner.insert_process(self.clone());
   568	        *process_group_mut = Arc::downgrade(&new_process_group);
   569	
   570	        Ok(())
   571	    }

   573	    /// Creates a new process group and moves the process to the group.
   574	    fn to_new_group(
   575	        self: &Arc<Self>,
   576	        current_session: Option<Arc<Session>>,
   577	        mut group_table_mut: MutexGuard<BTreeMap<Pgid, Arc<ProcessGroup>>>,
   578	    ) -> Result<()> {
   579	        let mut process_group_mut = self.process_group.lock();
   580	
   581	        let process_group = process_group_mut.upgrade().unwrap();
   582	        let session = process_group.session().unwrap();
   583	
   584	        if current_session.is_some_and(|current| !Arc::ptr_eq(&current, &session)) {
   585	            return_errno_with_message!(Errno::EPERM, "the process belongs to a different session");
   586	        }
   587	        if process_group.pgid() == self.pid {
   588	            // We'll hit this if the process is a session leader. There is no need to check below.
   589	            return Ok(());
   590	        }
   591	
   592	        let mut process_group_inner = process_group.lock();
   593	        let mut session_inner = session.lock();
   594	
   595	        // Remove the process from the old process group
   596	        process_group_inner.remove_process(&self.pid);
   597	        if process_group_inner.is_empty() {
   598	            group_table_mut.remove(&process_group.pgid());
   599	            session_inner.remove_process_group(&process_group.pgid());
   600	        }
   601	
   602	        // Create a new process group and insert the process to it
   603	        let new_process_group = ProcessGroup::new(self.clone(), Arc::downgrade(&session));
   604	        *process_group_mut = Arc::downgrade(&new_process_group);
   605	        group_table_mut.insert(new_process_group.pgid(), new_process_group.clone());
   606	        session_inner.insert_process_group(new_process_group);
   607	
   608	        Ok(())
   609	    }

   635	    /// Enqueues a process-directed signal.
   636	    ///
   637	    /// This method should only be used for enqueue kernel signals and fault signals.
   638	    ///
   639	    /// The signal may be delivered to any one of the threads that does not currently have the
   640	    /// signal blocked. If more than one of the threads have the signal unblocked, then this method
   641	    /// chooses an arbitrary thread to which to deliver the signal.
   642	    //
   643	    // TODO: Restrict this method with the access control tool.
   644	    pub fn enqueue_signal(&self, signal: impl Signal + Clone + 'static) {
   645	        if self.status.is_zombie() {
   646	            return;
   647	        }
   648	
   649	        let sig_dispositions = self.sig_dispositions.lock();
   650	
   651	        // Drop the signal if it's ignored. See explanation at `enqueue_signal_locked`.
   652	        let signum = signal.num();
   653	        if sig_dispositions.get(signum).will_ignore(signum) {
   654	            return;
   655	        }
   656	
   657	        let threads = self.tasks.lock();
   658	
   659	        // Enqueue the signal to the first thread that does not block the signal.
   660	        for thread in threads.as_slice() {
   661	            let posix_thread = thread.as_posix_thread().unwrap();
   662	            if !posix_thread.has_signal_blocked(signal.num()) {
   663	                posix_thread.enqueue_signal_locked(Box::new(signal), sig_dispositions);
   664	                return;
   665	            }
   666	        }
   667	
   668	        // If all threads block the signal, enqueue the signal to the main thread.
   669	        let thread = threads.main();
   670	        let posix_thread = thread.as_posix_thread().unwrap();
   671	        posix_thread.enqueue_signal_locked(Box::new(signal), sig_dispositions);
   672	    }

   769	    /// Sets all descendants of the current process as having child subreaper.
   770	    fn propagate_has_child_subreaper(&self) {
   771	        let mut process_queue = VecDeque::new();
   772	        let children = self.children().lock();
   773	        let Some(children_ref) = children.as_ref() else {
   774	            // The current process is exiting group at the same time.
   775	            return;
   776	        };
   777	        for child_process in children_ref.values() {
   778	            if !child_process.has_child_subreaper.load(Ordering::Acquire) {
   779	                process_queue.push_back(child_process.clone());
   780	            }
   781	        }
   782	
   783	        while let Some(process) = process_queue.pop_front() {
   784	            process.has_child_subreaper.store(true, Ordering::Release);
   785	            let children = process.children().lock();
   786	            let Some(children_ref) = children.as_ref() else {
   787	                // The process is exiting group at the same time.
   788	                continue;
   789	            };
   790	            for child_process in children_ref.values() {
   791	                if !child_process.has_child_subreaper.load(Ordering::Acquire) {
   792	                    process_queue.push_back(child_process.clone());
   793	                }
   794	            }
   795	        }
   796	    }

    24	/// create new task with userspace and parent process
    25	pub fn create_new_user_task(
    26	    user_ctx: Box<UserContext>,
    27	    thread_ref: Arc<Thread>,
    28	    thread_local: ThreadLocal,
    29	    is_init_process: bool,
    30	) -> Task {
    31	    let user_task_entry = move |user_ctx: UserContext| {
    32	        let current_task = Task::current().unwrap();
    33	        let current_thread = current_task.as_thread().unwrap();
    34	        let current_posix_thread = current_thread.as_posix_thread().unwrap();
    35	        let current_thread_local = current_task.as_thread_local().unwrap();
    36	        let current_process = current_posix_thread.process();
    37	        let (stop_waiter, _) = Waiter::new_pair();
    38	
    39	        let mut user_mode = UserMode::new(user_ctx);
    40	        user_mode.context_mut().activate_tls_pointer();
    41	        debug!(
    42	            "[Task entry] rip = 0x{:x}",
    43	            user_mode.context().instruction_pointer()
    44	        );
    45	        debug!(
    46	            "[Task entry] rsp = 0x{:x}",
    47	            user_mode.context().stack_pointer()
    48	        );
    49	        debug!(
    50	            "[Task entry] rax = 0x{:x}",
    51	            user_mode.context().syscall_ret()
    52	        );
    53	
    54	        // The `clone` syscall may require child process to write the thread pid to the specified address.
    55	        // Make sure the store operation completes before the clone call returns control to user space
    56	        // in the child process.
    57	        let child_tid_ptr = current_thread_local.set_child_tid().get();
    58	        if is_userspace_vaddr(child_tid_ptr) {
    59	            current_userspace!()
    60	                .write_val(child_tid_ptr, &current_posix_thread.tid())
    61	                .unwrap();
    62	        }
    63	
    64	        let has_kernel_event_fn = || current_posix_thread.has_pending();
    65	
    66	        let ctx = Context {
    67	            process: current_process,
    68	            thread_local: current_thread_local,
    69	            posix_thread: current_posix_thread,
    70	            thread: current_thread.as_ref(),
    71	            task: &current_task,
    72	        };
    73	
    74	        if is_init_process {
    75	            crate::init_in_first_process(&ctx);

fn clone_user_ctx(

    new_sp: u64,
    stack_size: Option<NonZeroU64>,

fn clone_pidfd(
    ctx: &Context,
    child: &Arc<Process>,
    clone_flags: CloneFlags,
    pidfd_addr: Option<Vaddr>,
) -> Result<()> {
    if !clone_flags.contains(CloneFlags::CLONE_PIDFD) {
        return Ok(());
    }

    let pidfd_addr = pidfd_addr.unwrap();

    let fd = {
        let pid_file = PidFile::new(child.clone(), false);
        let file_table = ctx.thread_local.borrow_file_table();
        let mut file_table_locked = file_table.unwrap().write();
        file_table_locked.insert(Arc::new(pid_file), FdFlags::CLOEXEC)
    };

    // Since `write_val` may sleep, we cannot hold the file table lock during its execution.
    // FIXME: Should we remove the file from the file table if the write operation fails?
    match ctx.user_space().write_val(pidfd_addr, &fd) {
        Ok(()) => Ok(()),
        Err(e) => {

            let mut file_table_locked = file_table.unwrap().write();
            file_table_locked.close_file(fd);
            Err(e)
        }
    }
}

fn set_parent_and_group(clone_flags: CloneFlags, parent: &Arc<Process>, child: &Arc<Process>) {
    loop {
        let real_parent = clone_parent(clone_flags, parent);

        // Lock the parent's children before checking its status.
        let mut children_mut = real_parent.children().lock();

        let Some(children_mut) = children_mut.as_mut() else {
            // The real parent is concurrently exiting group.
            // The children have been cleared,
            // so the retrial will see an up-to-date real parent.
            continue;
        };

        // Lock order: children of process -> parent of process
        child.parent().lock().set_process(&real_parent);

        // Update `has_child_subreaper` for the child process to
        // make sure the `has_child_subreaper` state of the child process
        // will be consistent with its parent.
        if real_parent.has_child_subreaper.load(Ordering::Relaxed) {
            child.has_child_subreaper.store(true, Ordering::Relaxed);
        }

        // Lock order: children of process -> process table
        // -> group of process -> group inner

        let mut process_table_mut = process_table::process_table_mut();

        let process_group_mut = parent.process_group.lock();

        let process_group = process_group_mut.upgrade().unwrap();
        let mut process_group_inner = process_group.lock();

        // Put the child process in the parent's process group
        process_group_inner.insert_process(child.clone());
        *child.process_group.lock() = Arc::downgrade(&process_group);

        // Put the child process in the parent's `children` field
        children_mut.insert(child.pid(), child.clone());

        // Put the child process in the global table
        process_table_mut.insert(child.pid(), child.clone());

        return;
    }
}

fn clone_parent(clone_flags: CloneFlags, current: &Arc<Process>) -> Cow<'_, Arc<Process>> {
    if clone_flags.contains(CloneFlags::CLONE_PARENT) {
        // The parent process of the current process cannot be `None`, since we have checked that
        // the current process is not the init process.
        Cow::Owned(current.parent().lock().process().upgrade().unwrap())
    } else {
        Cow::Borrowed(current)
    }
}

pub(super) fn exit_process(current_process: &Process) {
    current_process.status().set_zombie();
    current_process.status().set_vfork_child(false);

    // Drop fields in `Process`.
    current_process.lock_root_vmar().set_vmar(None);

    current_process.pidfile_pollee.notify(IoEvents::IN);

    send_parent_death_signal(current_process);

    move_children_to_reaper_process(current_process);

    send_child_death_signal(current_process);
}

/// Sends parent-death signals to the children.
//
// FIXME: According to the Linux implementation, the signal should be sent when the POSIX thread
// that created the child exits, not when the whole process exits. For more details, see the
// "CAVEATS" section in <https://man7.org/linux/man-pages/man2/pr_set_pdeathsig.2const.html>.
fn send_parent_death_signal(current_process: &Process) {
    let current_children = current_process.children().lock();
    for child in current_children.as_ref().unwrap().values() {
        let Some(signum) = child.parent_death_signal() else {
            continue;
        };

        // FIXME: Set `si_pid` in the `siginfo_t` argument.
        let signal = KernelSignal::new(signum);
        child.enqueue_signal(signal);
    }
}

/// Finds a reaper process for `current_process`.
///
/// If there is no reaper process for `current_process`, returns `None`.
fn find_reaper_process(current_process: &Process) -> Option<Arc<Process>> {
    let mut parent = current_process.parent().lock().process();

    while let Some(process) = parent.upgrade() {
        if is_init_process(&process) {
            return Some(process);
        }

        if !process.has_child_subreaper.load(Ordering::Acquire) {
            return None;
        }

        let is_reaper = process.is_child_subreaper();
        let is_zombie = process.status().is_zombie();
        if is_reaper && !is_zombie {
            return Some(process);
        }

        parent = process.parent().lock().process();
    }

    None
}

/// Moves the children of `current_process` to be the children of `reaper_process`.
///
/// If the `reaper_process` is zombie, returns `Err(())`.
fn move_process_children(
    current_process: &Process,
    reaper_process: &Arc<Process>,
) -> core::result::Result<(), ()> {
    // Take the lock first to avoid the race when the `reaper_process` is exiting concurrently.
    let mut reaper_process_children = reaper_process.children().lock();

    let Some(reaper_process_children) = reaper_process_children.as_mut() else {
        // The reaper process has exited, and it is not the init process
        // (since we never clear the init process's children).
        return Err(());
    };

    // Lock order: children of process -> parent of process
    // We holds the lock of children while update the children's parents.
    // This ensures when dealing with CLONE_PARENT,
    // the retrial will see an up-to-date real parent.
    let mut current_children = current_process.children().lock();
    for child_process in current_children.as_mut().unwrap().values() {
        let mut parent = child_process.parent.lock();
        reaper_process_children.insert(child_process.pid(), child_process.clone());
        parent.set_process(reaper_process);
    }
    *current_children = None;

    Ok(())
}

/// Moves the children to a reaper process.
fn move_children_to_reaper_process(current_process: &Process) {
    if is_init_process(current_process) {
        return;
    }

    while let Some(reaper_process) = find_reaper_process(current_process) {
        if move_process_children(current_process, &reaper_process).is_ok() {
            return;
        }
    }

    let Some(init_process) = get_init_process() else {
        return;
    };

    let _ = move_process_children(current_process, &init_process);
}

/// Sends a child-death signal to the parent.
fn send_child_death_signal(current_process: &Process) {
    let Some(parent) = current_process.parent().lock().process().upgrade() else {
        return;
    };

    if let Some(signal) = current_process.exit_signal().map(KernelSignal::new) {
        parent.enqueue_signal(signal);
    };
    parent.children_wait_queue().wake_all();
}

/// Sends `SIGKILL` to all other threads in the current process.
///
/// This is only needed when initiating an `exit_group` for the first time.
fn sigkill_other_threads(current_task: &CurrentTask, task_set: &TaskSet) {
    for task in task_set.as_slice() {
        if core::ptr::eq(current_task.as_ref(), task.as_ref()) {
            continue;
        }
        task.as_posix_thread()
            .unwrap()
            .enqueue_signal(Box::new(KernelSignal::new(SIGKILL)));
    }
}

/// Writes zero to `clear_child_tid` and performs a futex wake.
fn wake_clear_ctid(thread_local: &ThreadLocal) {
    let clear_ctid = thread_local.clear_child_tid().get();

    if clear_ctid == 0 {
        return;
    }

    let _ = current_userspace!()
        .write_val(clear_ctid, &0u32)
        .inspect_err(|err| debug!("exit: cannot clear the child TID: {:?}", err));
    let _ = futex_wake(clear_ctid, 1, None)
        .inspect_err(|err| debug!("exit: cannot wake the futex on the child TID: {:?}", err));

    thread_local.clear_child_tid().set(0);
}

/// Walks the robust futex list, marking futex dead and waking waiters.
///
/// This corresponds to Linux's `exit_robust_list`. Errors are silently ignored.
fn wake_robust_list(thread_local: &ThreadLocal, tid: Tid) {
    let mut robust_list = thread_local.robust_list().borrow_mut();

    let list_head = match *robust_list {
        Some(robust_list_head) => robust_list_head,
        None => return,
    };

    trace!("exit: wake up the rubust list: {:?}", list_head);
    for futex_addr in list_head.futexes() {
        let _ = wake_robust_futex(futex_addr, tid)
            .inspect_err(|err| debug!("exit: cannot wake up the robust futex: {:?}", err));
    }

    *robust_list = None;
}
